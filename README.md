# Медиасфера — гибрид-фаворит посадочной

Гибрид, собранный по итогам обратной связи команды: **белый лист-документ на лёгком воздушном фоне**, рукописные правки и стикеры-коты, контент урезан до основного. Три исполнения одной идеи — выбираем акцент.

| Вариант | Акцент |
|---|---|
| [A — редактура как герой](fav-a.html) | диффы «было → стало» в первом экране, дизайн демонстрирует продукт |
| [B — стикеры повсюду](fav-b.html) | коты-маскоты как наклейки с репликами, самый живой |
| [C — интерактив](fav-c.html) | максимум воздуха и движения, минимум текста |

Точка входа — **[index.html](index.html)** (разводящая с превью).

## Что заложено
- Белый лист по центру, фон лёгкий (off-white), **красный — только акцент** (логотип, маркер, CTA, ошейники котов).
- Рукописные пометки (Caveat, красным), маркер, диффы «было → стало», стикеры-маскоты.
- ~5 компактных секций вместо 7: hero → как доводим до продаж → кейсы → редакция + Яндекс → финал (FAQ + форма).
- Один CTA «Обсудить задачу», лид-магнит «Продаст или нет», без цен, рейтинг не на hero.

Чистый HTML/CSS/JS, без сборки. Лид-магнит на хостинге работает в демо-режиме (заглушка); для живого AI нужен бэкенд-эндпоинт.
